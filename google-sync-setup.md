# Панель 03: резервная копия на Google Диске

## Первое подключение с телефона

1. Открой [панель «Работа»](https://htongrad.github.io/03-rabota/) в том же Chrome, где настроено «Личное».
2. Нажми **⋯ → Google Диск → Настройки подключения → Заполнить из «Личного» → Сохранить настройки**.
3. Нажми **Подключить Google** и выбери прежний аккаунт.
4. Нажми **Выбрать папку** и укажи папку **03 РАБОТА**. Панель запомнит её и создаст копию.
5. В обзоре проверь состояние копии и время последней успешной отправки.

Если копия уже существует, панель сначала предложит восстановить её. Нажми **Восстановить с Диска**, проверь состав и подтверди **Восстановить**. Совпадающие записи сохраняют текущую локальную версию; отсутствующие добавляются. Только после подтверждения отправка объединённых данных продолжится.

## Если настройки из «Личного» недоступны

Вручную скопируй из настроек «Личного» Client ID, номер проекта и API key. Эти три значения относятся к одному проекту Google Cloud. Настройки разных панелей сохраняются отдельно; кнопка заполнения переносит только эти поля, без аккаунта, папки и рабочих данных.

Для нового проекта:

- Включи **Google Drive API** и **Google Picker API**.
- В Google Auth Platform настрой аудиторию приложения. Если приложение в тестовом режиме, добавь свой адрес в тестовых пользователей.
- Создай OAuth-клиент типа **Web application**, разрешённый JavaScript origin: `https://htongrad.github.io`.
- Client ID имеет окончание `.apps.googleusercontent.com`. Вставляй его без `https://`.
- Вставь числовой **Project number**, а не текстовый Project ID.
- Создай API key для Picker. Ограничь его HTTP referrer `https://htongrad.github.io/*` и Google Picker API.
- В панели заполни поля и сохрани настройки.

Панель запрашивает `openid` для проверки аккаунта и `https://www.googleapis.com/auth/drive.file` для работы с выбранной папкой и своей копией. Секрет клиента не используется.

## Повседневная работа

Рабочие данные остаются в браузере. В открытой панели изменения отправляются после небольшой паузы, если интернет доступен и разрешение Google действует. При возврате интернета отправка повторяется. В обзоре показываются состояние и время последней успешной отправки.

Доступ Google действует ограниченное время. После закрытия вкладки он не сохраняется. Нажми **Подключить Google**, когда панель предложит это; папку заново выбирать не нужно. При закрытой панели отправка по расписанию не выполняется.

**Отправить сейчас** запускает проверку и отправку вручную. **Отключить доступ** завершает доступ только в текущей вкладке, сохраняя настройки, локальные данные и файл на Диске.

Копия содержит все рабочие журналы и события панели 03, включая историю записей. Настройки подключения и токен доступа в неё не входят. Файл называется **Работа — резервная копия.json**. Панель находит его по собственной метке, а не по одному названию.

## Защита копии

Перед записью панель проверяет версию файла и передаёт условие `If-Match`. Если файл обновлён другим браузером, отправка приостанавливается до ручного восстановления. Если ответ Google потерялся, панель проверяет идентификатор операции и содержимое перед повторной записью. При повторе создания используется тот же заранее выделенный идентификатор файла.

На новом телефоне открой панель, подключи тот же аккаунт и проект, выбери папку, восстанови копию. Восстановление добавляет отсутствующие записи и сохраняет текущие совпадающие записи целиком. Перед заменой телефона дополнительно можно скачать файл через **⋯ → Копии данных → Сохранить копию**.

В этой версии Google Календарь ещё не подключён. События панели входят в резервную копию.

## Паспорт этапа

Принято: локальные данные — основной источник; Google Диск — резервная копия; ручное восстановление; автоматическая отправка в открытой панели; защита копии другого браузера. Дизайн продолжает «Модули» с жёлто-оранжевым акцентом; подсказки доступны рядом с настройками и действиями.

Реализован этап: резервирование на Google Диске. Проверены сценарии обмена на имитации API: создание, отправка изменений, пропуск неизменённых данных, автоматическая отправка, потеря ответа, повтор создания с тем же id, конфликт версии, восстановление, отключение. Восстановление также проверено через интерфейс. Вход, Google Picker и запись в реальном аккаунте, а также экранная клавиатура Android требуют проверки на телефоне.

Следующий этап: одностороннее зеркало событий в календаре «03 РАБОТА». Рекомендуемая модель — GPT‑6.1.
